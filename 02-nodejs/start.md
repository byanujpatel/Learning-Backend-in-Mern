## Notes to get started with Node.js and Express.js

- npm init for package json file
- package json file include which lib we use in project
- package-lock.json file include which dependency library version use in project
- node_modules is the folder where all the dependency library install in project
- it gives exact package version in package lock json
- npm install express
- Basic of functions including Callback
- IIFE - Self Invoked Function
- Basic of OS and FS as well
- Basic Module export from one file to another file
- Variable, function export
- Create a file using fileSystem
- Lodash library for Unique data and check type of data
